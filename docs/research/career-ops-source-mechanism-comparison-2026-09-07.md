# Career Ops source-mechanism comparison

Date: 2026-09-07

This audit compares the 19 sources advertised by Job Atlas with Career
Ops at commit
[`fe06051`](https://github.com/career-ops-hq/career-ops/tree/fe06051ba57c78934b89355bebe2c67f3a5cdb14).
The comparison is about **discovery and collection mechanism**, not Career
Ops' strong downstream ability to evaluate a job URL after it has been found.

## What “native” means here

Career Ops loads every non-helper module in `providers/*.mjs`; an explicit
`provider:` wins, followed by a configured local parser and then provider
auto-detection
([registry](https://github.com/career-ops-hq/career-ops/blob/fe06051ba57c78934b89355bebe2c67f3a5cdb14/providers/_registry.mjs#L24-L50),
[routing order](https://github.com/career-ops-hq/career-ops/blob/fe06051ba57c78934b89355bebe2c67f3a5cdb14/providers/_registry.mjs#L53-L93)).
I therefore counted a board as native only when that exhaustive provider
directory contains a provider for the board. The provider catalog and plugin
tree were also searched; no additional native implementations for the absent
boards were found
([provider tree](https://github.com/career-ops-hq/career-ops/tree/fe06051ba57c78934b89355bebe2c67f3a5cdb14/providers),
[supported-board catalog](https://github.com/career-ops-hq/career-ops/blob/fe06051ba57c78934b89355bebe2c67f3a5cdb14/docs/SUPPORTED_JOB_BOARDS.md),
[plugin tree](https://github.com/career-ops-hq/career-ops/tree/fe06051ba57c78934b89355bebe2c67f3a5cdb14/plugins)).

Career Ops still offers four generic routes for a source without a native
provider:

1. A user can add a `search_queries` entry, but the default `scan.mjs` does
   **not** execute it. An AI agent must run WebSearch, and the result is a
   search-index hit rather than a board traversal
   ([scanner boundary](https://github.com/career-ops-hq/career-ops/blob/fe06051ba57c78934b89355bebe2c67f3a5cdb14/modes/scan.md#L3-L7),
   [WebSearch stage](https://github.com/career-ops-hq/career-ops/blob/fe06051ba57c78934b89355bebe2c67f3a5cdb14/modes/scan.md#L150-L160)).
2. The agent can use Playwright on a configured `tracked_companies[].careers_url`.
   This path is designed for company career pages, not a ready-made board-wide
   connector
   ([Level 1](https://github.com/career-ops-hq/career-ops/blob/fe06051ba57c78934b89355bebe2c67f3a5cdb14/modes/scan.md#L112-L122)).
3. A user can write and configure their own local parser. That is an extension
   seam, not existing source support
   ([local-parser contract](https://github.com/career-ops-hq/career-ops/blob/fe06051ba57c78934b89355bebe2c67f3a5cdb14/modes/scan.md#L35-L86)).
4. Once a user already has a job URL, Career Ops can extract it with
   Playwright, then WebFetch, then WebSearch. LinkedIn may ultimately require
   pasted text
   ([URL inbox extraction](https://github.com/career-ops-hq/career-ops/blob/fe06051ba57c78934b89355bebe2c67f3a5cdb14/modes/pipeline.md#L115-L125)).

In the table, **No** means those generic routes do not reproduce the native,
paginated source collector. **Partial** means Career Ops has a native provider
for the same board, but its query, geography, pagination, or description depth
is materially different. **Near** means the normal collection path is broadly
equivalent, though implementation details differ.

## Conclusion

Career Ops is highly extensible, but configuration is not the same thing as
shipping a collector. Of these 19 named sources:

- **5 have native Career Ops providers:** Built In, Himalayas, We Work
  Remotely, Working Nomads, and Hacker News Hiring.
- **14 do not:** all eight India-focused boards plus LinkedIn, Indeed,
  Glassdoor, Wellfound, eFinancialCareers, and Talent.com.
- Of the five overlaps, Hacker News is near-equivalent. The other four are
  partial overlaps because Job Atlas uses India/role-filtered search or
  additional pagination/detail surfaces that Career Ops' broad provider does
  not.

Therefore Career Ops can be configured to *look for links* on every one of
these boards and can process a URL the user already has. It does not, without
new provider code, perform the same board-native collection for 14 of the 19
sources. That is the concrete distinction behind Job Atlas's current
India-specific discovery advantage.
