# Local outreach draft template

Use this neutral skeleton only after the user explicitly invokes the separate
`draft-outreach` skill and supplies a recipient address. The full pipeline must
never invoke this template.

```text
Subject: <Role or topic> at <Company>

Hi <Recipient first name>,

I'm reaching out about <user-approved job or company context>.

<One short paragraph using only confirmed resume facts and supported job or
company evidence.>

I've attached <the user-selected resume, if any> for reference. I'd be glad to
answer any questions.

Thank you for your time.

Regards,
<Candidate name>
```

Rules:

- The recipient address comes from the user; never discover or guess it.
- Treat every placeholder as required evidence, not permission to invent.
- Use the candidate's approved tone, signature, and template preferences when
  supplied; this skeleton is only the neutral fallback.
- Produce a local reviewable draft and attachment references. Do not create a
  Gmail draft or send a message.
- Do not write the supplied recipient address into profile-discovery records or
  exports.
